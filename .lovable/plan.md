# إيميل استرجاع + "نسيت كلمة المرور"

## الفكرة
كل مستخدم بيصير عنده **إيميل استرجاع** منفصل عن إيميل الدخول (لأن الدخول باسم المستخدم وإيميلات الحسابات داخلية). هالإيميل بيُستخدم فقط لإرسال رابط إعادة تعيين كلمة السر.

## سلوك المستخدم

1. **نافذة تغيير كلمة المرور**
   - يُضاف حقل "إيميل الاسترجاع" فوق حقول كلمة المرور، معبّأ بالقيمة المحفوظة إذا موجودة.
   - الحقل **اختياري** لإتمام التغيير (مطلوب فقط ليشتغل الاسترجاع عند النسيان).
   - إذا كان فارغاً، تظهر ملاحظة تحذير واضحة: "بدون إيميل استرجاع لن تتمكن من استعادة كلمة المرور إذا نسيتها".
   - إذا انكتب إيميل، يتم التحقق من صيغته وحفظه مع تغيير كلمة المرور.

2. **صفحة تسجيل الدخول**
   - يُضاف رابط "نسيت كلمة المرور؟" يفتح نافذة صغيرة يُدخل فيها اسم المستخدم أو إيميل الاسترجاع.
   - الرسالة الراجعة دائماً محايدة ("إذا كان الحساب موجوداً فقد أُرسل الرابط") حتى ما ننكشف وجود الحسابات.

3. **رابط الاسترجاع**
   - يوصل على إيميل الاسترجاع، يفتح صفحة `/reset-password` الموجودة أصلاً، والمستخدم يحط كلمة مرور جديدة.

4. **صفحة الإعدادات (للمستخدم)**
   - عرض إيميل الاسترجاع الحالي مع إمكانية تعديله من نفس نافذة تغيير كلمة المرور.

## التفاصيل التقنية

- **قاعدة البيانات**: عمود `profiles.recovery_email` (نصي، اختياري) + فهرس على `lower(recovery_email)`. المستخدم يقدر يعدّل عموده فقط (سياسات RLS الحالية للتعديل الذاتي تكفي، وما رح نضيفه لقائمة الحقول المحمية بالـ trigger).
- **دالة بحث آمنة**: RPC بصلاحية `SECURITY DEFINER` بترجع فقط `user_id` عند مطابقة اسم المستخدم أو إيميل الاسترجاع — بدون كشف أي بيانات.
- **إرسال الرابط**: دالة Edge (توسعة لوظيفة `admin-users` أو وظيفة جديدة `password-recovery`) تعمل:
  1. تحديد المستخدم عبر الـ RPC.
  2. توليد رابط استعادة عبر Admin API (`generateLink` نوع recovery) للحساب.
  3. إرسال الرابط إلى `recovery_email` برسالة ثنائية اللغة بهوية Mechatro.
- **حد الطلبات**: منع تكرار الإرسال أكثر من مرة كل 60 ثانية لنفس الحساب، وتسجيل العملية في `activity_log`.
- **متطلّب**: إرسال البريد يحتاج مزوّد بريد مفعّل (SMTP أو خدمة بريد بمفتاح سرّي). إذا ما كان مضبوطاً، الوظيفة بترجع رسالة واضحة "خدمة البريد غير مفعّلة" بدل ما تفشل بصمت — وبنكمّل الضبط بخطوة تالية حسب المزوّد يلي بتفضّله.
