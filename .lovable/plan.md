# حذف الجداول والصور داخل المستند

## الوضع الحالي
- شريط الأدوات فيه "حذف صف" فقط عند الوقوف داخل جدول عادي — ما في حذف عمود ولا حذف الجدول كامل.
- جدول البنود الذكي (Items) ما فيه أي زر حذف للجدول نفسه.
- الصورة فيها زر حذف لكن يظهر فقط بعد تحديدها، وغير واضح.

## الحل
### 1. أدوات الجدول العادي
عند الوقوف داخل جدول تظهر أزرار واضحة في الشريط:
- إضافة صف / إضافة عمود
- حذف صف / حذف عمود
- حذف الجدول كامل (مع تأكيد بسيط)
- دمج/فصل الخلايا (موجود)

### 2. جدول البنود الذكي
إضافة زر "حذف الجدول" داخل رأس البلوك الذكي بجانب أدوات الضريبة والخصم.

### 3. الصور
- زر حذف واضح في الشريط العائم فوق الصورة (موجود) + جعل الشريط يظهر أيضاً عند مرور الماوس على الصورة.
- دعم مفتاح Delete / Backspace لحذف الصورة أو الجدول الذكي أو فاصل الصفحة عند تحديده.

### 4. حذف عام لأي عنصر
إضافة زر "حذف العنصر المحدد" في الشريط يعمل على الصورة، جدول البنود، فاصل الصفحة، والحقل التلقائي.

## تفاصيل تقنية
- `Ribbon.tsx`: توسيع مجموعة الجدول بأوامر `deleteColumn` و`deleteTable`، وإضافة زر حذف عام يستخدم `deleteSelection` مع fallback على `deleteNode`.
- `extensions.tsx`: زر حذف في `ItemsTableView` عبر `deleteNode` من `NodeViewProps`، وضبط `selectable: true` للعقد الذرية.
- `ResizableImage.tsx`: إظهار الشريط عند hover بجانب selected، والاعتماد على سلوك ProseMirror الافتراضي لمفتاح Delete.
- CSS: تنسيق أزرار الحذف باللون التحذيري ضمن `.doc-ribbon` و`.doc-items-tools`.
