# تصنيفات أساسية جاهزة لصفحة إضافة مرجع

## الهدف
عرض مجموعة تصنيفات جاهزة (رقاقات chips) في `CategoryCombobox` تظهر مباشرةً حتى قبل أي بحث، بحيث المستخدم يختار بضغطة واحدة، مع الإبقاء الكامل على:
- شريط البحث/الكتابة.
- إمكانية إنشاء تصنيف جديد (زر "إنشاء" الذهبي).
- التصنيفات المستخرَجة من المراجع الموجودة.

## الملف
`src/routes/_authenticated/references.tsx` فقط — تعديل داخلي في `CategoryCombobox` مع تمرير التصنيفات الافتراضية عبر prop جديد.

## قائمة التصنيفات الافتراضية (ثنائية اللغة)
مبنية على طبيعة المشروع (إدارة مهام/مراجع فريق). كل عنصر عربي + إنجليزي — تظهر النسخة حسب `lang`:

| ar | en |
|---|---|
| توثيق | Documentation |
| أدوات | Tools |
| قوالب | Templates |
| مراجع | References |
| تصميم | Design |
| تطوير | Development |
| تعلّم | Learning |
| فيديو | Video |
| مقالات | Articles |
| روابط مهمة | Important links |

(10 تصنيفات تغطي معظم الحالات؛ سهل التوسعة لاحقاً.)

## التغييرات

**1) ثابت جديد `DEFAULT_CATEGORIES`** في أعلى `references.tsx`:
```ts
const DEFAULT_CATEGORIES: { ar: string; en: string }[] = [ ... ];
```

**2) في المكوّن `RefFormModal` (السطر ~628) اللي يستدعي `CategoryCombobox`:**
- تمرير prop جديد `defaults={DEFAULT_CATEGORIES.map(c => lang === "ar" ? c.ar : c.en)}` بجانب `options` (الفئات المستخرَجة من البيانات).

**3) توسيع `CategoryCombobox`:**
- إضافة prop `defaults: string[]` (اختياري، افتراضياً `[]`).
- دمج `defaults` مع `options` وإزالة التكرار (case-insensitive) لبناء قائمة موحّدة تُستخدم في الفلترة الحالية — بحيث الافتراضيات تظهر ضمن نفس الرقاقات (chips) الملوّنة بلا مسار مختلف.
- عرض التصنيفات الافتراضية حتى لما البحث فارغ والحقل ما مركّز عليه (حالياً `filtered` تظهر فقط لما في نتائج/تركيز — تحققت من الشرط `filtered.length > 0 || canCreate`؛ الافتراضيات ستدخل ضمن `filtered` فتظهر تلقائياً).
- إبقاء `slice(0, 24)` كسقف، لكن الأفضل رفعه لـ 30 عشان تسع الافتراضيات + المستخدمة سوا. سنستخدم 30.
- عنوان بصري صغير قبل الرقاقات: **"تصنيفات مقترحة"** / **"Suggested categories"** — يظهر فقط إذا لا يوجد بحث نشط ولا خيار مختار، ليعطي سياق للمستخدم بدون إزعاج.

**4) i18n:**
- إضافة مفتاح جديد `suggestedCategories`: `{ ar: "تصنيفات مقترحة", en: "Suggested categories" }` في `src/i18n/dict.ts`.

## سلوك متوقع
- عند فتح النموذج، حقل التصنيف يعرض الرقاقات مباشرة (افتراضيات + الموجود بالبيانات).
- الكتابة تفلتر القائمة كما هي.
- كتابة نص جديد لا يطابق أي تصنيف → يظهر زر "إنشاء" ذهبي.
- اختيار من الرقاقات = ملء الحقل فوراً.

## خارج النطاق
- بدون تعديل على شكل الرقاقات نفسها أو ألوانها.
- بدون تخزين التصنيفات الافتراضية في قاعدة البيانات — هي قائمة UI فقط.
- بدون تعديل على فلتر التصنيف في أعلى صفحة `/references` (يبقى معتمداً على التصنيفات المستخدمة فعلياً).

## التحقق
- `/references` → زر "إضافة مرجع" → حقل التصنيف يعرض الرقاقات مباشرة.
- الكتابة "توث" (عربي) تصفّي وتُبقي "توثيق".
- كتابة تصنيف جديد يظهر زر الإنشاء الذهبي.
- التبديل بين ع/EN يبدّل نصوص التصنيفات ونص "تصنيفات مقترحة".
