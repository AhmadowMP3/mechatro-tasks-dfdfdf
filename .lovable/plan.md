# إصلاح عرض «حسب الموظف» على الجوال

## المشكلة
عرض المهام حسب الموظف مبني كأعمدة جنب بعض تُمرَّر أفقياً (عرض كل عمود ~300–320px). على شاشة الجوال (~390px) يظهر جزء من العمود التالي على الحافة، فتبدو البطاقات متداخلة ومقصوصة، والتمرير الأفقي يتعارض مع التمرير العمودي داخل كل عمود.

## الحل
تحت 768px نستبدل الأعمدة الأفقية بقائمة عمودية واحدة، كل موظف = بطاقة قابلة للطي:

- صف الموظف (الصورة + الاسم + شارة الدور + عدد المهام + سهم فتح/طي) بعرض كامل، ارتفاع لمس ≥ 44px.
- عند الفتح: شرائح الحالات (مكتملة/موقوفة/…)، ثم شريط المؤشرات الثلاثة (نقاط / نسبة الإنجاز / ساعات)، ثم بطاقات المهام بعرض كامل بدون تمرير داخلي (تمرير الصفحة فقط).
- افتراضياً: أول موظف مفتوح والباقي مطوي، مع تذكّر آخر حالة أثناء الجلسة.
- إزالة `maxHeight: 620` و`overflowY` الداخلي على الجوال حتى لا يوجد تمرير داخل تمرير.
- شريط الأدوات أعلى العرض (Excel / PDF / الفلاتر): يلتف على سطرين بأزرار بعرض مناسب بدل الازدحام.

على الشاشات ≥ 768px يبقى العرض الحالي (أعمدة أفقية) كما هو تماماً بدون أي تغيير.

## تفاصيل تقنية
- التعديل داخل `src/components/tasks/MemberBoard.tsx` فقط + قواعد CSS في `src/styles.css`.
- استخدام هوك `useIsMobile` الموجود (768px) للتبديل بين البنيتين، مع الحفاظ على نفس البيانات والحسابات (`counts`, `overdue`, `points`, `completionRate`, `hours`) وعلى نفس `TaskCard`.
- لا تغيير في المنطق أو الصلاحيات أو التصدير — تخطيط وعرض فقط.
