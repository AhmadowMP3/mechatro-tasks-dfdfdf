# دليل إعداد Google Drive داخل صفحة الإعدادات

إضافة قسم «دليل الإعداد الكامل» أسفل بطاقة مزامنة Google Drive — شرح مفصّل خطوة بخطوة، ثنائي اللغة، بتصميم الموقع نفسه.

## ما سيظهر للمستخدم

بطاقة قابلة للطيّ (مغلقة افتراضياً) بعنوان **«دليل الإعداد الكامل — Google Drive»** أسفل بطاقة الربط، تحتوي:

1. **مسارَان واضحان في الأعلى**:
   - المسار الأسهل: الربط بحساب Google بضغطة (OAuth).
   - المسار المتقدّم: حساب خدمة (Service Account) — للسيرفرات المغلقة أو Shared Drive.

2. **خطوات مرقّمة** لكل مسار، كل خطوة ببطاقة صغيرة فيها رقم، عنوان، شرح، وما يلزم نسخه:
   - **OAuth**: إنشاء مشروع في Google Cloud → تفعيل Google Drive API → إعداد شاشة الموافقة (External + إضافة بريدك كـ Test user) → إنشاء OAuth Client ID نوع Web application → لصق عنوان الإرجاع → أخذ Client ID/Secret → إضافتهما لأسرار المشروع → العودة والضغط على «الربط بحساب Google» → اختيار المجلد أو إنشاؤه.
   - **Service Account**: إنشاء حساب خدمة → توليد مفتاح JSON → مشاركة مجلد Drive مع بريد الحساب بصلاحية Editor → رفع الملف من «خيارات متقدّمة» → إضافة المجلد.

3. **صناديق نسخ جاهزة** (زر «نسخ» بجانب كل قيمة):
   - عنوان الإرجاع (Redirect URI) للنطاق الحالي والمنشور.
   - النطاقات المصرّح بها (Authorized JavaScript origins).
   - أسماء الأسرار: `GOOGLE_OAUTH_CLIENT_ID`، `GOOGLE_OAUTH_CLIENT_SECRET`.
   - النطاقات (Scopes) المطلوبة: `drive.file`.
   - بريد حساب الخدمة الحالي (إن وُجد) لنسخه ولصقه في مشاركة المجلد.

4. **قسم «كيف تعمل المزامنة»**: نسخة تلقائية كل 10 أيام + النسخ اليدوية، ZIP واحد لكل نسخة، رفعها لكل مجلد مفعّل، الاحتفاظ بآخر 12 نسخة لكل مجلد، وسلوك الفشل (النسخة تبقى محفوظة محلياً ويظهر الخطأ).

5. **قسم استكشاف الأخطاء** (جدول: العَرَض ← السبب ← الحل) يغطّي:
   `redirect_uri_mismatch`، `access_denied` / التطبيق في وضع Testing، `Drive API has not been used`، `File not found` عند المجلد، «حصة حساب الخدمة صفر» ولماذا يجب مجلد مشترك أو Shared Drive، انتهاء صلاحية Refresh token، وخطأ «الملف ليس حساب خدمة صالحاً».

6. **قسم الأمان**: أين تُخزَّن البيانات (مشفّرة AES-256-GCM في الخادم)، أن المفتاح لا يُقرأ من المتصفح، وأن الوصول محصور بالمدير الأعلى.

## الجانب التقني

- مكوّن جديد `src/components/settings/DriveSetupGuide.tsx`:
  - عنصر قابل للطيّ باستخدام أنماط الموقع (`brand-card`, `var(--surface-2)`, `var(--border)`)، ودعم RTL/LTR عبر `useApp().lang`.
  - يستقبل `accountEmail`/`clientEmail`/`authMode` من حالة Drive لعرض القيم الفعلية داخل صناديق النسخ.
  - `redirectUri` يُحسب من `window.location.origin + "/api/public/google/drive-callback"` مع عرض نسخة النطاق المنشور أيضاً.
  - زر نسخ صغير لكل قيمة عبر `navigator.clipboard` + `toast.success`.
  - محتوى الخطوات في مصفوفة بيانات داخل الملف (نص عربي/إنجليزي جنباً إلى جنب في نفس المصفوفة) لتجنّب تضخيم `dict.ts` بعشرات المفاتيح؛ فقط عناوين الأقسام والأزرار تُضاف إلى `src/i18n/dict.ts`.
- تعديل `src/routes/_authenticated/settings.tsx`: عرض `<DriveSetupGuide … />` في نهاية `DriveConnectSection` (للمدير الأعلى فقط، مثل بقية البطاقة)، ويُفتح تلقائياً عندما لا يكون هناك ربط بعد.
- لا تغييرات في قاعدة البيانات ولا في الدوال الخادمية — عرض فقط.
