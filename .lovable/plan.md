# إنشاء مهمة بدون مشروع

## الهدف
جعل ربط المهمة بمشروع **اختياري** عند إنشاء المهمة، مع بقاء كل شيء يعمل في القوائم والتقارير.

## ما سيتغير

1. **قاعدة البيانات**: عمود `project_id` في جدول `tasks` يصير يقبل قيمة فارغة (nullable). لا تُحذف أي بيانات.
2. **نافذة "مهمة جديدة"**:
   - حقل المشروع يصبح اختياريًا ويظهر بجانبه وسم "اختياري"، وخيار "بدون مشروع" ضمن القائمة.
   - شرط التفعيل لزر الإنشاء لم يعد يتطلب اختيار مشروع.
   - عند اختيار "بدون مشروع" تُرسل القيمة فارغة بدل نص فارغ.
3. **العرض في كل المواضع** (بطاقة المهمة، الكانبان، الجدول، تفاصيل المهمة، لوحة التحكم، البحث السريع): المهام بلا مشروع تُعرض بشارة رمادية "بدون مشروع / No project" بدل شارة اسم المشروع، دون كسر التصميم.
4. **الفلاتر**: إضافة خيار "بدون مشروع" في فلتر المشروع بصفحة المهام.
5. **التقارير و Excel**: خانة المشروع تُطبع "—" للمهام غير المرتبطة بدل قيمة فارغة أو خطأ.
6. **الترجمة**: مفاتيح جديدة `noProject` و`optional` بالعربية والإنجليزية.

## تفاصيل تقنية
- Migration: `ALTER TABLE public.tasks ALTER COLUMN project_id DROP NOT NULL;` (المفتاح الأجنبي يبقى كما هو ويسمح بـ NULL).
- تعديل `src/components/NewTaskModal.tsx`: إزالة `form.project_id !== ""` من `isValid`، وإرسال `project_id: form.project_id || null`.
- الأنواع المولّدة لـ Supabase تتحدث تلقائيًا؛ أماكن `project_id: string` في الواجهات تُعدّل إلى `string | null` وتُحمى القراءات بـ optional chaining.
- لا تغيير على صلاحيات RLS. ملاحظة: صفحة تفاصيل المشروع تعرض مهام مشروعها فقط، فالمهام بلا مشروع تظهر في صفحة "المهام" ولوحة التحكم فقط.
