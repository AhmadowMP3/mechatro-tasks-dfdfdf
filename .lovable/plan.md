# إضافة الريال السعودي (SAR) لكل النظام

## الهدف
عملة ثالثة (بجانب SYP و USD) متاحة في كل مكان: المالية، الفواتير، الرواتب، الاشتراكات، التقارير، والمستندات التجارية — مع الرمز الرقمي الجديد للريال كأيقونة في الواجهة والمستندات، و"SAR" النصّي في ملفات Excel.

## ما سيتغيّر

### 1) قاعدة البيانات
- إضافة القيمة `SAR` إلى نوع العملات `currency_code` (كل الأعمدة الحالية تقبلها تلقائياً).
- إضافة عمود `sar_per_usd` لجدول أسعار الصرف مع قيمة افتراضية 3.75 للسجلات الحالية.
- سكربت SQL مطابق داخل `scripts/sql/` لتطبيقه على السيرفر الذاتي.

### 2) سعر الصرف
- في صفحة الإعدادات المالية: حقل جديد «SAR/USD» بجانب حقل SYP/USD في نفس نموذج تحديث السعر، ويُحفظ مع نفس التاريخ الفعّال.
- منطق التحويل يُعاد كتابته ليمرّ عبر الدولار: أي عملة → USD → العملة الهدف، باستخدام السعرين. إذا كان سعر الريال غير موجود يُستخدم 3.75 كقيمة احتياطية.

### 3) رمز الريال
- أيقونة SVG جديدة للرمز الرقمي للريال (`src/components/ui/RiyalSymbol.tsx` + نسخة كسلسلة SVG inline للمستندات المُصدَّرة).
- دالة تنسيق المبالغ تُرجع نصاً + معلومة العملة، ومكوّن عرض يضع الأيقونة بعد الرقم في الواجهة والورقة والـPDF (لأن الـPDF يُبنى من نفس HTML).
- في Excel والنصوص الخام (أسماء الملفات، سجلات النظام، ترويسة jsPDF النصية) يُستخدم `SAR`، مع تنسيق خلايا أرقام خاص بالريال.

### 4) أماكن الاختيار التي ستُحدَّث
- الإعدادات المالية (العملة الافتراضية).
- الفواتير (إنشاء/تعديل)، العملاء، الإيرادات، المصاريف، الاشتراكات (إيراد ومصروف)، الرواتب وإعدادات رواتب الأعضاء.
- مُبدِّل عملة العرض في لوحة المالية وصفحة التقارير المالية (يصير ثلاثة أزرار: SYP / USD / SAR).
- الإعدادات الافتراضية لقوالب المستندات التجارية (تُضاف SAR للقائمة).
- قاموس الترجمة: مفتاح `sar` = «ريال سعودي» / «SAR».

### 5) العملة الافتراضية
تبقى كما هي (SYP للمالية، USD للمستندات) والريال خيار إضافي.

## تفاصيل تقنية
- ترحيل: `ALTER TYPE public.currency_code ADD VALUE 'SAR';` ثم `ALTER TABLE public.fx_rates ADD COLUMN sar_per_usd numeric DEFAULT 3.75;` + تحديث السجلات القديمة.
- `src/lib/finance.ts`: `formatMoney` يتعامل مع ثلاث عملات (الرمز بعد الرقم للريال والليرة، وقبله للدولار)، و`convertAmount(amount, from, to, rates: { sypPerUsd, sarPerUsd })` — كل نداءات الدالة الحالية (لوحة المالية، التقارير، المصاريف، الإيرادات، الفواتير) تُحدَّث لتمرير كائن الأسعار.
- `src/lib/finance-xlsx.ts` و`src/lib/finance-list-export.ts`: تنسيق `#,##0.00" SAR"` وتصدير نصي.
- بلا كسر للأنواع: `Currency` مشتق من enum قاعدة البيانات، فبعد الترحيل تتحدّث الأنواع تلقائياً.

## التحقق
- إنشاء فاتورة ومصروف وإيراد بالريال، والتأكد من ظهور الرمز في الواجهة، وفي معاينة الورقة، وفي PDF، و«SAR» في Excel.
- تبديل عملة العرض في لوحة المالية والتقارير والتأكد من صحة التحويل بالسعرين.
