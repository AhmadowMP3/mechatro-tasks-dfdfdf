# ما ينقص تشغيله على Supabase الاستضافة الذاتية

آخر التعديلات على قاعدة البيانات صارت على القاعدة السحابية، والاستضافة الذاتية (supabase.mechatro-sy.com) ما وصلها. المطلوب: ملف SQL واحد جاهز للصق والتشغيل، آمن للتكرار (idempotent).

## الجديد الذي لم يُشغَّل بعد

1. **نظام احتساب النقاط الجديد** — أهم شي:
   - دالة `settle_task_points(task_id)` المركزية (توزيع النقاط على أكثر من عضو، ومنع الحساب المزدوج، وعكس الرصيد القديم عند إضافة توزيع جديد).
   - تحديث دالة `award_points_to_user` + `award_task_points`، وتريغرات المهام و`task_point_awards` (AFTER INSERT OR UPDATE).
   - الصلاحيات: تنفيذ الدالة لـ service_role فقط.
   - إعادة احتساب شاملة للمهام المكتملة السابقة، وإعادة بناء `profiles.total_points` و`season_scores`.
2. **مفاتيح النقاط والشارات** — `user_badges.user_id` و`season_scores.user_id` تشير إلى `public.profiles(id)` بدل `auth.users` (كانت تسبّب خطأ عند اعتماد التوزيع لمستخدم بلا حساب auth).
3. **نظام المستندات التجارية** (عرض سعر / RFQ / Offer / فاتورة / فاتورة مبدئية / أمر شراء): جداول `doc_templates`, `business_docs`, `business_doc_revisions`, `doc_counters` + `next_doc_number()` و`doc_type_prefix()`. الملف موجود مسبقاً `scripts/sql/2026-08-24-business-docs.sql` — يُدمج داخل الملف الموحّد ليضمن التشغيل.
4. **تنظيف روابط المشاركة**: إزالة سياسات وجدول `share_links` (الميزة أُلغيت من الواجهة).
5. **تدقيق سريع** في نهاية الملف: استعلامات تتحقق أنه لا يوجد توزيع نقاط معلّق، وأن أرصدة الأعضاء مطابقة لمجموع `task_point_awards`.

## طريقة التنفيذ

- إنشاء ملف واحد: `scripts/sql/2026-08-24-selfhost-sync.sql` بترتيب: المستندات التجارية ← مفاتيح النقاط ← دوال/تريغرات النقاط ← إعادة الاحتساب ← إزالة share_links ← استعلامات التحقق.
- تحديث `scripts/sql/README` أو تعليق داخل الملف بخطوات: SQL Editor على الاستضافة الذاتية ← لصق ← Run (قابل للتشغيل أكثر من مرة بدون ضرر).
- لا تعديل على كود الواجهة؛ الكود الحالي يعمل مباشرة بعد تشغيل الملف.

## ملاحظات تقنية

- كل `CREATE` بصيغة `IF NOT EXISTS` / `CREATE OR REPLACE`، والـ enums داخل `DO $$ ... EXCEPTION WHEN duplicate_object`.
- إعادة الاحتساب تُنفَّذ ضمن معاملة واحدة مع تعطيل التريغرات مؤقتاً كي لا تتضاعف الإشعارات.
- الأشياء غير المتعلقة بقاعدة البيانات (متغيرات Google Drive والـ edge functions) خارج نطاق هذا الملف؛ إذا بدك أراجعها كمان خبرني.
