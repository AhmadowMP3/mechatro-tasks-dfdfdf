# عرض "حسب الموظف" في صفحة المهام

تبويب رابع في صفحة المهام يعرض المهام موزّعة على أعمدة كانبان، عمود لكل موظف، مع إحصائيات لكل موظف وتصدير PDF/Excel. متاح للأدمن والماستر أدمن فقط.

## ما سيُبنى

**1. زر عرض جديد**
- إضافة خيار `byMember` إلى `ViewSwitcher` بجانب البطاقات/كانبان/الجدول (أيقونة أشخاص).
- يظهر الزر فقط للأدمن؛ إذا كان العرض المحفوظ `byMember` وفتح عضو عادي الصفحة، يرجع تلقائياً لعرض البطاقات.

**2. لوحة الأعمدة (مكوّن جديد `MemberBoard`)**
- عمود لكل موظف نشِط + عمود أخير "غير مسند".
- تمرير أفقي مثل كانبان الحالي، وعلى الموبايل الأعمدة تصير مكدّسة عمودياً.
- رأس كل عمود: الصورة الرمزية، الاسم، شارة الدور، ثم شريط إحصائيات:
  - عدد المهام حسب الحالة (قيد الانتظار / جاري / قيد المراجعة / مكتمل) كشارات ملوّنة.
  - عدد المتأخرة بالأحمر.
  - مجموع النقاط ونسبة الإنجاز (المكتمل ÷ الإجمالي).
  - مجموع ساعات العمل المسجّلة من `work_sessions`.
- داخل العمود: نفس بطاقة المهمة الحالية (`TaskCard`) بحجم مضغوط، والنقر يفتح نافذة تفاصيل المهمة كالمعتاد.
- المهمة ذات عدة مكلَّفين تظهر في عمود كل واحد منهم.

**3. الفلاتر والبحث**
- العرض يستخدم نفس المهام المفلترة الحالية (المشروع، الحالة، الأولوية، المتأخرة، البحث)، فتغيير أي فلتر ينعكس فوراً على الأعمدة.
- ترتيب الأعمدة: الأكثر مهاماً مفتوحة أولاً، مع إمكانية إخفاء الموظفين بدون مهام (مفتاح صغير أعلى اللوحة).

**4. التصدير**
- زر تصدير في رأس اللوحة:
  - **PDF**: بنفس القالب الداكن الموحّد (لوغو ميكاترو، هيدر/فوتر) — صفحة ملخّص فيها جدول الموظفين وإحصائياتهم، ثم قسم لكل موظف بجدول مهامه.
  - **Excel**: ورقة ملخّص + ورقة تفصيلية (موظف، عنوان المهمة، المشروع، الحالة، الأولوية، الاستحقاق، متأخرة؟، النقاط، الساعات).
- التصدير يحترم الفلاتر الحالية.

**5. الترجمة**
- إضافة مفاتيح: `viewByMember`، `unassigned`، `openTasks`، `completionRate`، `loggedHours`، `hideEmptyMembers`، `exportByMember` بالعربي والإنجليزي.

## تفاصيل تقنية

- ملف جديد: `src/components/tasks/MemberBoard.tsx` (عرض فقط، بدون منطق DB جديد).
- ملف جديد: `src/lib/report/by-member-report.ts` لبناء PDF بالاعتماد على `src/lib/pdf/chrome.ts` الموجود، و`src/lib/export/xlsx.ts` لملف Excel.
- الساعات: استعلام تجميعي واحد على `work_sessions` (`user_id`, `duration_minutes`) عبر React Query داخل صفحة المهام، بدون تغيير في المخطط أو سياسات RLS.
- النقاط تُقرأ من `tasks.points` / `points_awarded_amount` الموجودة أصلاً.
- تعديلات محدودة: `ViewSwitcher.tsx` (خيار رابع)، `tasks.tsx` (فرع عرض + الاستعلام + التصدير)، `i18n/dict.ts` (مفاتيح).
- لا تغييرات على قاعدة البيانات.
