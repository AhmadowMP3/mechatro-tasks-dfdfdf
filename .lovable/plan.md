# زر واحد لإعادة تعيين الخزنة المالية

## الوضع الحالي (مؤكد من الكود)

- شاشة التشخيص تعرض جدولاً بعدد الصفوف الكلي وعدد الصفوف المشفّرة لكل جدول مالي، وفي حالتك عدد المشفّر = 0 في كل الجداول.
- إعادة التعيين اليوم تتطلب: كتابة كلمة «حذف» + خيار حذف السجلات + زر أحمر، ثم بعدها يجب فتح شاشة أخرى لتعيين عبارة جديدة (`setup`). خطوتان منفصلتان ومربكتان.

## المطلوب

زر واحد ينهي كل شي عندما لا توجد بيانات مشفّرة.

### 1. رسالة حالة واضحة أعلى اللوحة

- إذا عدد المشفّر = 0: شريط أخضر بخط كبير: «لا توجد بيانات مالية مشفّرة — إعادة التعيين آمنة تماماً ولن تفقد أي شيء».
- إذا > 0: شريط تحذير برتقالي بعدد السجلات المهدّدة، ويبقى المسار القديم (كتابة «حذف») كما هو.

### 2. زر «إعادة تعيين وتعيين عبارة جديدة»

يظهر فقط عندما عدد المشفّر = 0، ويقوم بالتالي في نقرة واحدة:

1. يفتح حواراً صغيراً فيه حقلان: العبارة الجديدة + تأكيدها، مع مؤشر قوة العبارة.
2. عند الضغط على «تأكيد»: يحذف مفتاح الخزنة القديم (`reset`) ثم ينشئ المفتاح الجديد فوراً (`setup`) بالعبارة التي كتبتها، ويصبح النظام مفتوحاً (unlocked) مباشرة.
3. رسالة نجاح: «تم تعيين عبارة المرور المالية الجديدة».

بدون كتابة كلمة «حذف»، وبدون خيار حذف السجلات (لأنه لا يوجد شي ليُحذف).

### 3. تبسيط القسم الأحمر

- القسم التدميري القديم يبقى لكنه يُطوى تلقائياً (قابل للفتح بنص «خيارات متقدّمة») عندما عدد المشفّر = 0، فلا يظهر خطر بلا داعٍ.
- خيار «احذف أيضاً السجلات المشفّرة» يُخفى عندما العدد صفر.

### 4. نفس الزر متاح من شاشة القفل

الرابط «العبارة لا تُقبل؟» في شاشة القفل يفتح نفس اللوحة، فيصل المستخدم لهذا الزر بدون الحاجة لفتح المالية.
