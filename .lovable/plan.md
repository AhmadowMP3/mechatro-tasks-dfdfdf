# Creative Minimal Member Report PDF

Redesign the member report PDF into a clean, editorial, bilingual layout with the Mechatro logo in the header and `mechatro @ mechatro.hub4tech.net` in the footer on every page. Keep the existing generation pipeline (html2canvas + jsPDF, Montserrat Arabic font, storage + history) untouched — only visuals change.

## Design direction — "Creative Minimal"

- **Palette:** paper `#FCFCFC`, ink `#0B0B0B`, muted `#8A8A8A`, hairline `#ECECEC`, single accent `#42C2EE` (Mechatro cyan) + gold `#D4A017` for the divider rule.
- **Type:** Montserrat + Montserrat Arabic (already loaded). Massive display weights (900) for headings, ultra-light muted labels in ALL CAPS with wide letter‑spacing. No boxes, no gradients — dividers and whitespace only.
- **Bilingual pattern:** each section title shows Arabic (bold, large) + English (uppercase micro‑label) stacked. KPI cards show one big number with EN label on top and AR label under.
- **Motifs:** thin 2px accent bars, generous 56px page margins, one hairline gold rule under the cover title, dotted separators between rows.

## Pages

1. **Cover** — top‑left: logo (28px) + "MECHATRO · REPORT" micro‑label. Center: giant name `full_name` (56px, black 900), thin cyan bar + AR/EN subtitle "تقرير العضو / Member Report", circular avatar (140px) beside role + status chips. Bottom strip: period · generated on · generated by, hairline separator.
2. **Snapshot (KPIs)** — 4‑up grid: Total tasks · Completion % · On‑time % · Hours logged. Each: big number 64px + EN caption + AR caption + tiny sparkline of that metric.
3. **Charts** — Left column: donut (status breakdown). Right column: 12‑week activity sparkline area. Below: horizontal bar list of top projects. All rendered as inline SVG (existing helpers, restyled minimal).
4. **Tasks list** — hairline table: title · project dot · status pill · due · completed. Groups by status with big section number "01 · Done", "02 · In Progress", etc.
5. **Work sessions** — compact rows: date · duration (HH:MM) · task title. Totals footer.
6. **Activity log** — timeline strip, dot + timestamp + action label, max 30 latest.

## Header & footer on every page

Add a shared chrome block injected at the top and bottom of every `<section class="pdf-page">` (except the cover uses its own header):

- **Header (h=44px):** logo 24px left · thin hairline · page title EN / AR right. RTL flip when `lang="ar"`.
- **Footer (h=36px):** left `mechatro @ mechatro.hub4tech.net`, right page number `03 / 08` (rendered from section index and total sections known at build time). Hairline top border.

Because the current pipeline rasterises each `.pdf-page` and can split it into multiple A4 tiles, the header/footer are painted **inside each section's HTML** rather than natively via jsPDF — this keeps everything in one code path and matches how the existing themes work.

## Technical changes

- `src/lib/report/themes.ts` — add a fourth theme `creative` (id, palette, cover config). Keep existing three intact.
- `src/lib/report/report-html.ts`
  - New helpers: `pageChrome(lang, pageTitleAr, pageTitleEn, pageNo, pageTotal)` returning header+footer HTML fragments.
  - New builder branch when `getTheme().id === "creative"` for `coverPage`, `kpiGrid`, charts section, tasks section, sessions section, activity section — using the minimal layout described above.
  - `buildBilingualHtml` gets a `creative` code path that stacks AR+EN within each section instead of side‑by‑side pages, producing a single bilingual document.
  - Wrap every non‑cover `.pdf-page` with the chrome fragments; compute `pageTotal` by counting sections after they're assembled.
- `src/components/team/GenerateReportDialog.tsx` — add a fourth style card "Creative" (label AR: "إبداعي بسيط", EN: "Creative Minimal") to the theme picker grid; wire `theme = "creative"`.
- `src/i18n/dict.ts` — add `themeCreative` key (AR/EN) and any new section micro‑labels used in the chrome (e.g. `page`, `of`).

## Out of scope

- No new fonts, no new dependencies.
- Existing themes (aurora / executive / minimal) untouched — users can still pick them.
