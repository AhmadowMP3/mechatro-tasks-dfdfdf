# مطابقة عدد صفحات PDF مع صفحات المستند

## الحالة الحاليّة (من الكود)
- `DocPaper` ورقة واحدة مطاطية (`minHeight: 1123px` وتطول مع المحتوى)، والترقيم ثابت `1 / 1`.
- التصدير في `export-doc.tsx` يطبع هذه الورقة الواحدة داخل iframe، و`@page { size: A4; margin: 12mm }` تضيف هوامش فوق هوامش الورقة — فينتج قصّ وصفحات فاضية وعدد صفحات لا يطابق المعاينة.

## الهدف
عدد صفحات ملف PDF = عدد صفحات الورقة في المعاينة، بدون قصّ ولا صفحات فارغة، مع ترويسة وتذييل وترقيم صحيح في كل صفحة.

## الخطة
1. **ترقيم حقيقي (Pagination)**
   - مكوّن جديد `src/components/documents/PaginatedDoc.tsx`:
     - يقيس ارتفاع كل بلوك من `DocBody` في حاوية مخفية بعرض A4.
     - يوزّع البلوكات على صفحات بحسب المساحة المتاحة (ارتفاع A4 ناقص ارتفاع الترويسة والتذييل الفعلي).
     - لا يقسم الجدول عند صفٍّ ناقص: صفوف الجدول تُقسم على صفحات ويُعاد رأس الجدول في كل صفحة.
   - يُخرِج مصفوفة صفحات، كل صفحة `DocPaper` بارتفاع A4 ثابت (بدون تمدد) و`page={{ current, total }}` صحيح.

2. **CSS الطباعة**
   - في `print-document.ts`: `@page { size: A4; margin: 0 }` (الهوامش موجودة داخل الورقة أصلاً).
   - كل صفحة: `width: 794px; height: 1123px; overflow: hidden; break-after: page;` وآخر صفحة بدون `break-after` — هذا يمنع الصفحة الفارغة الأخيرة.
   - `break-inside: avoid` للصفوف والبطاقات كما هو.

3. **المعاينة والتصدير من نفس المصدر**
   - `export-doc.tsx` يطبع `PaginatedDoc` بدل ورقة واحدة.
   - معاينة المحرِّر (`documents.$id.tsx`) تستخدم نفس `PaginatedDoc` مع فراغ بصري بين الصفحات، فيصير اللي تشوفه = اللي يُطبع.
   - تصدير Word (`export-html.ts`) ياخذ نفس التقسيم ويضع فاصل صفحة صريح بين الصفحات.

4. **فحص**
   - اختبار مستند قصير (صفحة واحدة) ومستند طويل (٣+ صفحات) والتأكد أن آخر صفحة غير فارغة وأن الترقيم «الصفحة ٢ / ٣» صحيح، بالعربي والإنجليزي وبالوضعين فاتح/غامق.

## تفاصيل تقنية
- القياس يتم مرة واحدة بعد تحميل الخطوط والصور (`document.fonts.ready` + `img.onload`) لتفادي اختلاف الأطوال بين القياس والطباعة.
- ارتفاع الترويسة/التذييل يُقاس فعلياً (لأنه يتغيّر بحسب الشعار والملاحظات) وليس بقيمة ثابتة.
- لا تغييرات على قاعدة البيانات.
