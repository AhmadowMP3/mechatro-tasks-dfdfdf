# محرر مستندات بستايل الوورد

استبدال نظام البلوكات بمحرر كتابة حرة داخل ورقة A4 نفسها، مع كل أدوات التنسيق (خطوط، أحجام، ألوان، جداول، صور، فواصل صفحات)، وبنفس الهيدر والفوتر الرسمي وصف QR الحالي.

## شكل الشاشة الجديد

```text
┌──────────────────────────────────────────────┐
│  شريط أدوات لاصق (Ribbon)                    │
│  خط | حجم | B I U S | لون | تمييز | محاذاة   │
│  قوائم | تباعد | RTL/LTR | جدول | صورة | QR  │
├──────────────────────────────────────────────┤
│        ورقة A4 بيضاء (نفس الهيدر الرسمي)     │
│        ← الكتابة تصير مباشرة هنا →           │
│        (فوتر رسمي + صف QR محفوظ)             │
└──────────────────────────────────────────────┘
```

## الأدوات المطلوبة

- خطوط: Montserrat / Montserrat Arabic / Arial / Times، أحجام 8–48، لون النص، تمييز، Bold/Italic/Underline/Strike، مرتفع/منخفض.
- فقرات: عناوين H1–H3، قوائم نقطية ومرقمة، محاذاة (يمين/وسط/يسار/ضبط)، تباعد أسطر، مسافة بادئة، اتجاه RTL/LTR لكل فقرة.
- إدراج: جدول (إضافة/حذف صفوف وأعمدة، دمج خلايا، رأس جدول)، صورة بالرفع أو اللصق، رابط، خط فاصل، فاصل صفحة يدوي.
- حقول تلقائية: رقم المستند، التاريخ، اسم العميل، العملة، المجموع الفرعي، الضريبة، الإجمالي — تُدرَج كـ chip وتتحدّث لوحدها عند تغيير بيانات المستند.
- جدول البنود الذكي يبقى موجودًا كعنصر قابل للإدراج داخل النص (حساب تلقائي للمجاميع والضريبة).
- Undo/Redo، لصق من الوورد مع تنظيف التنسيق الزائد، عدّاد صفحات.

## المستندات القديمة

تُحوَّل تلقائيًا عند أول فتح: كل بلوك (عنوان/نص/جدول/مفتاح-قيمة/شروط/بنود/فاصل) يتحوّل لمحتوى منسّق داخل المحرر، ويُحفظ بالشكل الجديد. لا فقدان بيانات — النسخة القديمة تبقى مخزّنة كنسخة احتياطية داخل السجل.

## التصدير

- **PDF**: نفس مسار الطباعة الحالي على ورقة A4 مع الهيدر/الفوتر الرسمي وصف QR في الصفحة الأخيرة.
- **Word**: تصدير HTML متوافق مع الوورد يحافظ على الخطوط والألوان والجداول.
- الترقيم التلقائي يقسم المحتوى على صفحات دون قطع الجداول أو الصور في نصّها.

## تفاصيل تقنية

- محرر: TipTap 3 (موجود مسبقًا بالمشروع) + إضافات FontFamily / TextStyle / Color / Highlight / TextAlign / Table / Image / Link / HorizontalRule + عقدة مخصصة `pageBreak` وعقدة `itemsTable` وعقدة inline `docField`.
- نموذج البيانات: إضافة حقل `content_html` (أو `content_json`) إلى صف المستند مع `schema_version = 2`؛ `blocks` القديمة تبقى للقراءة/التحويل.
- ملفات جديدة: `src/components/documents/editor/DocEditor.tsx`، `Ribbon.tsx`، `extensions/*.ts`، `src/lib/docs/convert-legacy.ts`.
- تعديل: `DocPaper.tsx` (يعرض محتوى المحرر بدل البلوكات)، `paginate.ts` (تقسيم DOM بدل قائمة بلوكات مع الحفاظ على `QR_ROW_H`)، `export-html.ts`، `documents.$id.tsx`.
- تنقية HTML عند الحفظ والعرض عبر `src/lib/security/sanitize.ts` لمنع أي حقن.
- CSS الطباعة: `@page A4`، منع `break-inside` داخل الصفوف والصور، خطوط مضمّنة للعربية.

## الخطوات

1. عقد ومخزن المحرر + مخطط الحفظ الجديد.
2. شريط الأدوات الكامل بكل المجموعات الأربع.
3. عرض داخل ورقة A4 مع الهيدر/الفوتر الرسمي والترقيم.
4. محوّل المستندات القديمة.
5. تصدير PDF/Word + QR.
6. فحص شامل: مستند عربي، مستند إنجليزي، جدول طويل يمتد صفحتين، صورة، فاصل صفحة يدوي.
