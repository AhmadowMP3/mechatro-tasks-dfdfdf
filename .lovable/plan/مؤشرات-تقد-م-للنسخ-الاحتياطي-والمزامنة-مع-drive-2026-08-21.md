# مؤشرات تقدّم للنسخ الاحتياطي والمزامنة مع Drive

الهدف: لا تبقى أي عملية (إنشاء نسخة، مزامنة مع Drive، استعادة، تحميل، حذف) صامتة. كل عملية تُظهر تقدّماً مرئياً ومراحل واضحة.

## ما سيظهر للمستخدم

1. **شريط تقدّم علوي داخل بطاقة النسخ الاحتياطية**
   - يظهر فور بدء أي عملية طويلة (إنشاء نسخة / استعادة / مزامنة).
   - يعرض: اسم المرحلة الحالية + نسبة مئوية + شريط متحرّك بلون هوية الموقع.
   - مراحل إنشاء النسخة: تحضير ← قراءة قاعدة البيانات ← ضم ملفات التخزين ← رفع النسخة ← مزامنة Drive ← تم.
   - مراحل الاستعادة: قراءة الملف ← التحقق ← استعادة الجداول ← استعادة الملفات ← تم.

2. **حلقة تقدّم صغيرة على الأزرار (Icon buttons)**
   - زر المزامنة/الاستعادة/الحذف الخاص بالصف قيد التنفيذ يتحوّل إلى دائرة تقدّم صغيرة بدل الأيقونة، وبقية الأزرار تُعطَّل أثناء ذلك.

3. **زر "إنشاء نسخة الآن"**
   - يتحوّل إلى حالة "جارٍ…" مع سبينر ونص المرحلة، غير قابل للضغط مرتين.

4. **نتيجة نهائية واضحة**
   - عند النجاح: الشريط يمتلئ أخضر مع "تمت العملية" ثم يختفي بعد ثانيتين، وتُحدَّث القائمة تلقائياً.
   - عند الفشل: الشريط يتحوّل أحمر ويعرض رسالة الخطأ المختصرة مع رابط إلى لوحة سجل الأخطاء الموجودة.

## التفاصيل التقنية

- الاستدعاءات الحالية إلى `backup-snapshot` عبارة عن نداء واحد لا يبثّ تقدّماً، لذلك سيُبنى مُشغّل مراحل في الواجهة: hook جديد `useOperationProgress` يقود التقدّم بمراحل زمنية متوقّعة (يتقدّم تدريجياً حتى 90% ويقفز إلى 100% عند وصول الرد الفعلي) — فلا يوجد ادّعاء بنسبة غير حقيقية عند النهاية.
- مكوّن جديد `src/components/settings/BackupProgress.tsx` (شريط + نص مرحلة + حالة نجاح/فشل) بتصميم الموقع الداكن وبالعربية/الإنجليزية.
- مكوّن صغير `SpinnerIcon` يُستخدم داخل `IconBtn` الحالي في `src/routes/_authenticated/settings.tsx` عبر خاصية `loading`.
- تعديل الدوال: `createBackup` (manual)، `syncToDrive`، `restore`، `deleteBackup` في `src/routes/_authenticated/settings.tsx` لتشغيل/إنهاء التقدّم مع تمرير معرّف الصف الجاري.
- مفاتيح ترجمة جديدة في `src/i18n/dict.ts` لأسماء المراحل ونصوص النجاح/الفشل.
- لا تغيير في Edge Function ولا في قاعدة البيانات.
